# SET - Higher Level Programming

This repository contains JavaScript programming projects completed as part of the ALX Software Engineering / Higher Level Programming curriculum. 

## Projects Covered
* **0x12-javascript-warm_up**: Introduction to JavaScript syntax, variables, conditionals, loops, functions, objects, and closure basics following `semistandard` style guidelines.
* **0x13-javascript_objects_scopes_closures**: Advanced object-oriented programming in JavaScript using ES6 class notation, inheritance (`extends`, `super`), instance methods, and module exports.

## Requirements & Standards
* Allowed editors: `vi`, `vim`, `emacs`
* All files interpreted/compiled on Ubuntu 20.04 LTS using Node.js (version 14.x)
* Code adheres strictly to `semistandard` linting rules (single quotes, semicolons, no `var`)
* All script files are executable (`chmod +x`) and start with `#!/usr/bin/node`
